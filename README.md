## About me

I work with **Java and Python** across Android applications, Java web projects, and AI coursework, with **HTML, CSS, and JavaScript** for browser interfaces. My repositories include personal utilities and team projects: a budget manager, a car-rental marketplace, a fashion store, a stock-market simulation, and board games with computer opponents.

I enjoy connecting application logic, data, and interface design: tracking everyday expenses, managing a rental flow, keeping game turns in sync, or comparing machine-learning models.

- **Android:** Native Java apps with XML layouts, local SQLite storage, and Firebase services.
- **Web:** Spring Boot applications and MVC websites built with Jakarta Servlet, JSP, and MySQL.
- **Python & AI:** Flask applications, data analysis, classification models, and experiments with RNN/LSTM time series.
- **Teamwork:** Experience leading the CarVIA coursework team and working on shared application features.

## Selected projects

### [Personal Budget Manager](https://github.com/pvhNam/Personal-Budget-Manager)

A native Android expense tracker with local SQLite storage and a focus on everyday budgeting.

- Income and expense tracking with editable categories, search, and monthly filters.
- Monthly budgets, recurring transactions, and savings goals with contribution history.
- Interactive bar and donut charts for reports and monthly summaries.
- XML-based screens with custom glass effects, animations, and profile customization.

**Stack:** Java / Android / XML / SQLite / Gradle

### [CarVIA — Car & Driver Rental](https://github.com/pvhNam/LTMobile)

A team-built Android marketplace for self-drive rentals and rentals with a driver, with customer, driver, and admin flows.

- Vehicle listings, rental requests by day or trip, and pickup/destination selection.
- Driver trip management, real-time chat, push notifications, favorites, and reviews.
- An internal wallet with VNPay sandbox top-ups and administration tools.
- Firebase services with an MVVM and Repository architecture.

**My contribution:** Team lead; Liquid Glass interface design, core rental screens, vehicle-sale listings, wallet and VNPay integration, invoices, favorites, and reviews.

**Stack:** Java / Android / Firebase / Cloud Functions / Cloudinary / Google Maps / VNPay Sandbox / Gradle

### [Fashion E-Commerce Website](https://github.com/pvhNam/ThucTapWeb)

A team-built fashion store covering the customer shopping flow and store administration.

- Product search, category filters, color/size variants, reviews, cart, and vouchers.
- Google OAuth login, email OTP password recovery, and Vietnamese/English interfaces.
- Checkout with MoMo sandbox or cash on delivery, saved addresses, and order history.
- Admin tools for products, inventory, orders, users, news, and Excel revenue reports.

**Stack:** Java / Jakarta Servlet / JSP / JSTL / MySQL / HTML / CSS / JavaScript / Apache Tomcat / Gradle

### [Mobile Price Classification](https://github.com/pvhNam/MayHoc)

A machine-learning coursework project comparing four models for classifying mobile phones into price ranges.

- SVM, Random Forest, XGBoost, and MLP models.
- Exploratory analysis of 2,000 labeled samples with 20 features and four classes.
- A stratified train/test split, with scaling inside model pipelines where needed.
- Model comparisons, confusion matrices, learning curves, and predictions for unlabeled data.

**Stack:** Python / pandas / NumPy / scikit-learn / XGBoost / Matplotlib / Seaborn

### [Stock Market Simulation & Time-Series Experiments](https://github.com/pvhNam/DoAn_Python)

A learning project combining a Flask stock dashboard, simulated trading, and experiments with stock-price models.

- User accounts, a market board, and stock-detail pages with price history.
- Simulated buy/sell orders, portfolio tracking, and transaction history.
- LSTM and SimpleRNN training scripts with saved models and comparison results.
- Time-series features including RSI, MACD, and Bollinger Bands.

**Stack:** Python / Flask / MySQL / pandas / NumPy / TensorFlow/Keras / HTML / CSS

### [O An Quan — Spring Boot Web Game](https://github.com/pvhNam/oanquan)

A browser version of the traditional Vietnamese board game, combining a Java game engine with an interactive web interface.

- Local play, a computer opponent, and online rooms with room codes and matchmaking.
- REST endpoints for game state, moves, and move history.
- WebSocket/STOMP updates for games and the lobby.
- Responsive layouts, animated stone distribution, and turn/result feedback.

**Stack:** Java / Spring Boot / Thymeleaf / WebSocket / JPA / H2 / Maven / HTML / CSS / JavaScript

### [Othello AI Game](https://github.com/pvhNam/DoAn_TTNT)

A desktop AI coursework project with a Java Swing board and a computer opponent.

- Human-versus-computer play on an 8 × 8 board.
- Minimax search with a depth of five plies.
- Weighted evaluation using board position, mobility, and disc-count difference.
- Legal-move hints, move highlights, live scores, and game restart controls.

**Stack:** Java / Swing / Minimax / Heuristic Evaluation / MVC

## How I work

I aim to make projects useful, understandable, and easier to improve.

- Start with a clear use case and build a working flow.
- Connect interface decisions with application logic and data.
- Separate responsibilities through patterns such as MVC, MVVM, and repositories.
- Review edge cases, document setup steps, and improve through each iteration.
